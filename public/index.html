    Configurações do Git AutoSync
    
        
    

        
    
          
    
            
              Token do GitLab
              ?Usado pelo Git AutoSync para criar Merge Request. Fica nas variáveis de ambiente
                  do seu usuário do Windows (GIT_AUTOSYNC_GITLAB_TOKEN e GIT_AUTOSYNC_GITLAB_HOST),
                  não no arquivo de dados do HUB SNK.
            

            
    
              
              
            
    

            
    
              
              
    
                
                
                
              
    
            
    

            
    
              
    
              
            
    
            
    
              O token gravado nunca é mostrado: deixe o campo em branco para manter o atual. A
              bandeja do Git AutoSync já aberta só enxerga o token novo depois de reaberta.
            
    
          
    
          
    
        
    

        
    
          
          
        
    
      
    
        

    
    
      
    
        
    Git AutoSync
    
        
    Ferramenta à parte do HUB SNK, com licença e repositório próprios.
    
      
    
      
    
        
    
          Faz commit e push automáticos dos repositórios cadastrados nele, num horário fixo pela
          tarefa agendada do Windows ou quando você pedir. A mensagem do commit pode ser escrita por
          IA (Claude Code, Codex ou OpenCode) ou ser uma mensagem fixa, e cada repositório pode ter
          a sua política de arquivos e de branches.
        
    
        
    
          No HUB SNK, a aba Git AutoSync mostra o estado de cada repositório, os horários, o log e
          as ações de commit, push, sincronização e merge request. Ele também tem ícone na bandeja,
          linha de comando e skill para agentes de IA.
        
    
        
    Precisa do Git instalado na máquina.
    
      
    
      
    
        Abrir o repositório
        
      
    
        

    
    
      
    
        
    O Git não está instalado
    
        
    O Git AutoSync usa o Git em todo commit e push: instale o Git antes.
    
      
    
      
    
        
    
          Baixe e instale o Git em
          https://git-scm.com/. Depois, clique em Verificar de novo. Se o Git já estiver instalado e ainda assim não
          for encontrado, reinicie o HUB SNK: ele só enxerga o PATH novo depois de reaberto.
