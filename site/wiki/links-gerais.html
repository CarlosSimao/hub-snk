Links gerais

Os links gerais guardam os endereços avulsos do cliente, como o portal de chamados, a pasta de arquivos e a documentação, a um clique de distância. Ficam na aba Geral do cliente, abaixo das anotações. Os links de um projeto ficam no próprio projeto.

Nesta página

  1. Ver os links gerais
  2. Cadastrar link geral
  3. Abrir link
  4. Copiar, editar e excluir link

Ver os links gerais

A seção Links gerais mostra cada link pelo nome, com os botões de copiar, editar e excluir ao lado. Cliente sem link mostra Nenhum link cadastrado para este cliente. Com anotações ou links gerais, o cliente já abre na aba Geral.

Passo a passo

  1. Selecione o cliente e, se ele não abrir na aba Geral, clique nela. A seção Links gerais fica abaixo de Anotações gerais.

Configurações que dependem ou alteram

Nenhuma.

Depende de

  • Lista e detalhe do cliente
  • Divide a aba Geral com as anotações gerais.
  • Os links de um projeto ficam em Links do projeto.

Cadastrar link geral

Guarda um endereço com um nome. O Nome do link tem até 120 caracteres e a URL, http ou https, até 300; os dois são obrigatórios. A mesma URL não pode repetir entre os links gerais do cliente.

Passo a passo

  1. Na seção Links gerais, clique no +.
  2. Na janela Cadastrar link, preencha o Nome do link e a URL.
  3. Clique em Salvar. O link entra no fim da lista, e o aviso Link cadastrado. confirma.

Configurações que dependem ou alteram

Nenhuma.

Depende de

  • Ver os links gerais

Abrir link

O nome do link é clicável. No aplicativo, com os links abrindo no navegador do HUB SNK (o padrão), ele abre numa guia própria, com o nome do cliente e do link, sem preencher login. Se já houver uma guia aberta no mesmo site, como a de uma base do cliente, essa guia vai até o endereço do link. Com os links abrindo no navegador padrão, o link abre lá, com a sessão que o navegador já tiver. Isso vale mesmo para um link que aponte para uma tela da base: ele abre como link, sem o login automático da base.

Passo a passo

  1. Na seção Links gerais, clique no nome do link.
  2. O site abre numa guia nova do HUB SNK ou no navegador padrão.

A guia própria é do aplicativo desktop. Com o Painel aberto num navegador comum, o link abre numa aba nova desse navegador.

Configurações que dependem ou alteram

  • Configurações › Geral › Abrir os links em: Navegador do HUB SNK ou Navegador padrão. Vale no próximo clique.

Depende de

  • Cadastrar link geral
  • Onde os links abrem
  • Mesma guia que a base aberta no mesmo site.
  • Também abre pela busca rápida, com Enter num link.

Copiar, editar e excluir link

Os três botões à direita do link copiam a URL para a área de transferência, abrem a edição do nome e da URL, com as mesmas regras do cadastro, e excluem o link do cliente.

Passo a passo

  1. Para copiar a URL, clique no primeiro botão. O aviso Link copiado. confirma.
  2. Para editar, clique no lápis.
  3. Na janela Editar link, altere o nome ou a URL e clique em Salvar. O aviso Link atualizado. confirma.
  4. Para excluir, clique na lixeira vermelha.
  5. Na janela Excluir link, clique em Excluir. Não há como desfazer.
