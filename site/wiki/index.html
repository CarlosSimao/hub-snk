Cada página do menu é uma área do HUB SNK. Dentro dela, cada funcionalidade tem o passo a passo com prints, as configurações que mudam o comportamento dela e links para as funcionalidades de que ela depende.

Todos os nomes, endereços e mensagens dos prints são fictícios.
