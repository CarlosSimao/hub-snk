Instalação

O instalador ainda não tem assinatura digital, por isso o navegador e o Windows mostram avisos. Os passos abaixo explicam como seguir.

  1. Baixe o instalador

    Clique em Baixar para Windows. Ele sempre traz a versão mais recente.

    Se o navegador disser que o arquivo não é baixado com frequência, escolha Manter. No Edge, fica no menu ··· do aviso de download.

  2. Rode o HUB-SNK-Setup.exe

    Ele instala só para o seu usuário e não pede senha de administrador.

    Se aparecer "O Windows protegeu o computador", clique em Mais informações › Executar assim mesmo.

  3. Responda as boas-vindas

    Na primeira abertura, quatro passos rápidos: seus dados (opcionais), o seu perfil — Consultor, Analista, Gerente de Projetos ou Desenvolvedor, que marca as abas visíveis — e se você tem login no SankhyaOm e na Experience. Tudo muda depois em Configurações.

  4. Salve o seu Sankhya ID

    Em seguida, na primeira vez, a aba Sankhya ID das Configurações já abre. Salve usuário e senha, que valem para o SankhyaOm e a Experience, junto com o seu código de usuário SankhyaOm, que filtra a agenda. A partir daí, as guias logam sozinhas.

No Linux (Ubuntu, Debian e derivados): baixe o pacote .deb, instale com sudo apt install ./hub-snk-amd64.deb e abra o HUB SNK pelo menu de aplicativos. A partir daí, os passos são os mesmos. O Git AutoSync é só do Windows.
No Mac (Apple Silicon, em versão beta): baixe o HUB-SNK.dmg, arraste o HUB SNK para Aplicativos e libere a primeira abertura como mostra a wiki: o app não é assinado pela Apple. As versões novas são instaladas à mão, pelo aviso do Painel.

Bom saber

Atualizar

O HUB SNK baixa a versão nova sozinho e avisa quando ela está pronta; é só reiniciar. No Mac, o Painel avisa e a versão nova é instalada por cima. O cadastro continua onde está.

Desinstalar

No Windows, em Configurações › Aplicativos › HUB SNK. No Linux, sudo apt remove hub-snk-desktop. O cadastro não é apagado.

Recursos opcionais

O Git precisa estar instalado para os recursos de repositório e para o Git AutoSync, e o Docker, para o banco local.

Dúvidas ou Sugestões

No HUB SNK, abra Configurações › Sobre e clique em Reportar problema ou sugerir. Escolha se é um problema, uma sugestão ou uma dúvida, escreva com as suas palavras e clique em Enviar.
