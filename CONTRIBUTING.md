# Como pedir alguma coisa

Este projeto é mantido por uma pessoa só, e o código é escrito só por ela.
**Não abra pull request** — ele não será revisado.

O que ajuda é o pedido bem escrito. Os canais estão no
[README, em Suporte](README.md#suporte): erro vai em issue, ideia e dúvida vão
em Discussions, falha de segurança vai por e-mail.

Cite sempre a versão que aparece no rodapé da tela, e lembre que **o repositório
é público** — nada de senha, host, usuário ou nome de cliente no que você colar.

A licença é [MIT](LICENSE): fazer um fork e seguir por conta própria está
liberado.
